# Strategic Data Collection & Preprocessing Blueprint — Week 1

Design artefacts and a working reference implementation for collecting and
cleaning publicly available logistics data with Python.

The written submission is
`reports/Week1_Strategic_Data_Collection_and_Preprocessing_Blueprint.docx`.
Everything in this repository exists either to support that document or to
prove that its claims run: the pipeline described in the report is executed by
`src/run_pipeline.py` on every run, and the numbers quoted in the report are
read from its output.

## What is here

```
virtualinternship1/
├── config/schema.yml          # column contract: dtypes, allowed vocabularies, bounds
├── data/raw/                  # immutable landed extract (committed: synthetic, seeded)
├── data/processed/            # curated output (regenerated; git-ignored)
├── docs/
│   ├── sources.md             # public data source register with licence notes
│   ├── data_dictionary.md     # every published column and the rule behind it
│   ├── decision_log.md        # 18 decisions, alternatives rejected, rationale
│   ├── figures/               # diagrams, generated by src/make_figures.py
│   └── week1_blueprint.md     # report source (pandoc-ready)
├── src/
│   ├── ingest.py              # landing-zone reader, checksum provenance
│   ├── clean.py               # transforms + cleaning log
│   ├── validate.py            # declarative checks, critical vs warning
│   ├── run_pipeline.py        # land -> clean -> validate -> publish -> report
│   ├── make_sample_data.py    # seeded generator for the messy extract
│   └── make_figures.py        # regenerates the diagrams
├── tests/test_clean.py        # 19 unit tests
└── reports/                   # quality report (generated) + submitted .docx
```

## Run it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python -m src.make_sample_data      # regenerate the messy extract (fixed seed)
python -m src.run_pipeline          # clean, validate, publish, write report
python -m pytest -q                 # 19 tests
python -m src.make_figures          # regenerate the diagrams
```

Exit code is `0` only when every critical validation check passes.

## Design position

- The raw extract is immutable. Everything is re-derived, never patched.
- Coerce or reject; never guess silently. Unparseable values become null and
  are counted, not imputed away.
- Missing data is a classification problem (MCAR / MAR / MNAR) before it is an
  imputation problem. Every filled value carries a flag.
- Validation gates publication; warnings are recorded rather than fatal.
- Every figure, report and table in this repository is generated from code.

See [`docs/decision_log.md`](docs/decision_log.md) for the reasoning, including
the decisions that were reversed.
