# Decision log

Each entry records a decision that a reviewer might otherwise have to
reverse-engineer from the code. Entries are appended, never rewritten: a
wrong decision that was later reversed is more useful to a reader than a
tidied history.

| id | date | decision | alternative rejected | why |
|---|---|---|---|---|
| D-01 | 2026-10-27 | Develop against a seeded synthetic extract, then swap in a real public dataset | Starting with a Kaggle download | Licensing of the useful freight datasets is unclear or paid; a synthetic extract lets the pipeline be public and reproducible while the defects remain realistic |
| D-02 | 2026-10-27 | Read the raw file entirely as text | Let pandas infer dtypes | Inference silently mangles identifiers with leading zeros and dates with ambiguous day/month order |
| D-03 | 2026-10-27 | Keep the raw file immutable and re-derive everything | Clean in place, iteratively | Re-deriving from a checksummed original is the only way to prove a change in output came from a change in code |
| D-04 | 2026-10-28 | Parse dates with an explicit format list, first match wins | `pd.to_datetime(..., infer_datetime_format=True)` / `format="mixed"` | Guessing turns 04/03 into April in one file and March in another; an explicit list is boring and auditable |
| D-05 | 2026-10-28 | Delete dots when building alias keys | Replace punctuation with a space | `U.S.A.` must collide with `USA`, while `U.A.E.` must not become `u a e` |
| D-06 | 2026-10-28 | Unmapped vocabulary values become null and are logged, not passed through | Keep the original string | A silent pass-through means a typo becomes a new "country"; validation later catches the null and the run fails loudly, which is the point |
| D-07 | 2026-10-28 | Weight is converted with the exact international pound (0.45359237 kg) | 0.454 or `0.45` | A 0.1% error is invisible per row and material across a year of tonnage |
| D-08 | 2026-10-28 | A currency code printed on the amount outranks the `currency` column | Trust the column | The amount travelled with the money; the column is frequently the report default, not the transaction currency |
| D-09 | 2026-10-28 | FX uses a pinned snapshot (EUR 1.09, GBP 1.27, INR 0.012) | Live ECB call at run time | Pinned rates make the published figures reproducible; a live rate makes yesterday's report irreproducible. Production would store the daily rate table and version it |
| D-10 | 2026-10-28 | Deduplicate by keeping the last row per shipment key | Keep first, or keep the most complete row | Freight systems emit a row per status change, so the last row is the most recent state; "most complete" biases towards whichever field happened to be edited |
| D-11 | 2026-10-28 | Impute weight with a median grouped by mode × category, falling back to mode, then global | Mean, or a single global median | Weights are log-normal and the mean is dragged by one mis-scaled pallet; mode is the strongest available predictor of consignment size |
| D-12 | 2026-10-28 | Impute cost from median USD per kg within mode | Median cost | An empty 20 kg air consignment and an empty 20 kg ocean container do not cost the same |
| D-13 | 2026-10-29 | Every imputed value carries a boolean flag | Impute silently, document in prose | A model can use the flag; prose cannot be joined back to a row |
| D-14 | 2026-10-29 | Negative freight costs are kept, then clipped at zero | Drop them | They are credit notes and are real revenue events; dropping them overstates cost |
| D-15 | 2026-10-29 | Critical checks fail the run (non-zero exit); warnings do not | One severity for everything | A pipeline that dies on every soft anomaly never finishes; one that publishes through hard ones never gets trusted |
| D-16 | 2026-10-29 | Carrier promise is taken as the p90 of observed transit per mode | Contract table | No contract data is public; p90 is a defensible stand-in and is stated in the report rather than implied |
| D-17 | 2026-10-31 | Time zones and geospatial joins (port polygons, OSM routing) are scoped out of week 1 | Half-implementing both | Both need a reference dataset and a spatial index; scoping them out honestly beats a shallow implementation |
| D-18 | 2026-10-31 | Figures are generated by `src/make_figures.py` | Screenshots and diagram exports | A PNG that cannot be rebuilt from a checkout is a liability during review |
