# Week 2 — Exploratory Data Analysis and Visualisation

**Status:** not started. Due in the week beginning 7 November 2026.

## Task as set

Perform exploratory data analysis on a public logistics dataset using Python:
uncover trends, outliers and patterns, apply visualisation and statistical
analysis, and document the exploratory process, the interpretations and the
recommendations in a Word report. Charts must be embedded images produced with
matplotlib, seaborn or plotly, and every visualisation needs explanatory text
describing what it shows and what follows from it.

## Input

`week1/data/processed/shipments_clean.csv` — 4,200 typed rows, one row per
shipment, with imputation flags and a resolved currency. Using the week 1
output rather than starting fresh is the point of keeping one repository.

## Planned analysis

1. Univariate distributions for weight, cost, transit and quantity, on a log
   scale where the distribution is heavy-tailed.
2. Lane and mode comparisons; cost per kilogram by mode.
3. Outlier and concentration analysis; the top-decile share of tonnage.
4. A time dimension across the despatch year, testing for seasonality.
5. A check that imputed rows are not systematically different — the flag
   columns exist for exactly this.

## Definition of done

- Every figure regenerated by a committed script, not a notebook cell.
- Each figure accompanied by an interpretation, not a caption.
- The report explains what the data cannot support, not only what it suggests.
